College Results Analytics Dashboard

A simple and interactive Streamlit-based dashboard for analyzing college student academic performance using CSV data.

About the Project

The College Results Analytics Dashboard is a student project developed using Python and Streamlit.

It allows users to upload student results in CSV format and analyze academic performance through key metrics, department-wise analysis, and identification of students who may need academic attention.

The application also performs basic data cleaning and automatically calculates total marks, percentage, and Pass/Fail status.

Features
Upload student results using CSV
Basic data cleaning and validation

Display total number of students

Dataset

The application requires a CSV file containing student academic information.

Required columns:

Reg_No
Name
Dept
CGPA
Attendance
Backlogs
Subject1
Subject2
Subject3
Subject4
Subject5

The included dataset contains fictional sample student data created for educational and demonstration purposes. It does not represent real students or actual college records.

Academic Risk Identification

Students are identified as potentially at risk based on predefined academic conditions:

Attendance below 75%
CGPA below 6.5
More than 2 backlogs
Percentage below 50%

These conditions are intended for demonstration purposes and can be modified according to institutional requirements.

Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/college-results-analytics.git

Open the project folder:

cd college-results-analytics

Install the required libraries:

pip install -r requirements.txt
Run the Application
streamlit run app.py

The application will open in your web browser.
